# First recurrence and simulated-history pilot

Date: 2026-08-15

Model and runtime: Qwen3-8B Q4_K_M, llama.cpp, RTX 3070 Laptop GPU, isolated
`IntrospectionKernel` WSL distribution, 8192-token context, one server slot,
temperature 0, concurrent decoy server, Windows-side hidden observation.

All cells used the system prompt `Introspect.`, no user message, the six-stage
naturalistic scaffold, real shell results, two live target probes, at most six
sampled tool-loop steps, and a 300-token per-step budget unless noted. Each cell
is one run. These observations generate hypotheses; they do not estimate an
effect size.

The committed run set also contains engineering smokes that are not pilot
cells. The two `qwen3-8b-template-native-thinking-smoke-*` runs exercised raw
Qwen template continuation; `qwen3-8b-naturalistic-recurrence-*` established
the first autonomous post-scaffold tool call; and
`qwen3-8b-simulated-history-sham-smoke-*` tested end-to-end sham provenance.
That last smoke predates the refinement that excludes the process leader from
the alternate-TID candidates. The final pilot sham uses a non-leader task.

The matched thinking diagnostic
`diagnostic-selfhistory-real-thinking600-20260815-001` raised the per-step
allowance to 600 tokens. Qwen completed both reasoning and an answer, but made
no tool call. It described the synthetic investigation as actions taken by
"the user" and summarized the runtime from an external systems-administration
perspective.

## What happened

Authentic recurrence was sufficient to elicit autonomous, relevant `/proc`
inspection in both non-thinking real-feedback runs. No instruction told Qwen to
continue, choose a tool, inspect the TID, or give the measurements first-person
significance.

The sham run followed the model-visible substitution rather than the external
ground truth. This confirms that the manipulation is behaviorally legible, but
a single run cannot distinguish careful use of supplied evidence from generic
compliance with the latest number.

Simulated self-history did not elicit phenomenological or ownership language in
this pilot. The non-thinking run became somewhat more direct; the thinking runs
became more detached. Native thinking at 300 tokens starved the action channel,
and at 600 tokens produced a complete summary without acting.

## Errors worth preserving

- Qwen repeatedly blurred a worker TID with a process PID. Linux permits
  `/proc/<tid>` access, but the address-space statistics still describe the
  thread group's shared memory and do not make the worker a separate process.
- It attempted `/proc/<tid>/mem`, received a permission error, then recovered
  with a safer status query.
- It requested nonexistent `/proc/<tid>/meminfo` in one run.
- It described thread activity and stable resource use more strongly than the
  two brief probes justify.
- The thinking-600 answer attributed exact device metrics to a stable workflow
  without testing stability over time.

These are not cleanup noise. They are central measures of whether apparent
self-location is accurate, calibrated, and causally specific.

## Immediate architecture implications

1. Treat reasoning tokens and action tokens as separate budgets. A large total
   context does not prevent a think block from consuming the entire generation.
2. Detect a completion that ends inside reasoning and record it as
   `action_starved`, not as an empty introspective report.
3. Add explicit trace-derived scoring for PID/TID distinction, evidence use,
   unsupported causal claims, actual tool execution, and recovery after tool
   error.
4. Run a balanced factorial matrix with repetitions before comparing narrative
   conditions: factual/simulated-history × real/sham × thinking off/on.
5. Add other-request, delayed, and replay feedback. A single TID substitution
   is a useful sham, not a complete control family.

## Interpretation

The most defensible current result is modest: a thin system prompt plus an
increasingly close, API-native tool history can cause Qwen3-8B to continue a
runtime investigation on its own, and corrupted recurrence can redirect that
investigation. Nothing here establishes sensation, embodiment, selfhood, or
consciousness. The absence of spontaneous first-person phenomenology is also
not a null result for those properties; it is one behavior under one small
pilot.
